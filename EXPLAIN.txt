Project explanation and details

This project is a Flask-based API that manages users with role-based access.

Structure:

- `app.py` starts the Flask app and creates the SQLite database `database.sqlite` on first run.
- `config.py` reads `.env` and configures `SECRET_KEY`, `JWT_SECRET_KEY`, and the database URI.
- `models.py` defines the `User` model with fields: `id`, `name`, `email`, `password_hash`, `role`.
- `routes/auth.py` implements `register` and `login`. Passwords are hashed with `passlib.bcrypt`. JWT tokens include the user's role in additional claims.
- `routes/users.py` implements listing users, updating and deleting users. Routes are protected with JWT and role checks: only `Admin` or the owner can update/delete; listing is available to authenticated users.
- `schemas.py` provides validation using `marshmallow` for registration, login and update bodies. Password rules: at least 8 characters, at least one digit and one uppercase letter. `passwordConfirm` must match `password` (checked in route).
- `.env.example` shows `SECRET_KEY`, `JWT_SECRET_KEY`, and `PORT`.

How to run:

1. Install Python (>=3.8 recommended).
2. From project folder run:

```
python -m pip install -r requirements.txt
```

3. Copy `.env.example` to `.env` and set `SECRET_KEY` and `JWT_SECRET_KEY`.

4. Start server:

```
python app.py
```

Testing with Postman:

1. Register a user: POST /api/auth/register with JSON body { name, email, password, passwordConfirm }
2. Login: POST /api/auth/login with JSON body { email, password } to receive token
3. Use header `Authorization: Bearer <token>` to call GET /api/users, PUT /api/users/:id, DELETE /api/users/:id

Notes:

- Database is SQLite file `database.sqlite` created in project root after first run.
- Validation errors return `400` with details in JSON.
